# Echocare

Echocare is a project by **Darcy** and **Nathaniel**.

It is a therapeutic conversation application that uses AI-powered emotion detection, empathetic responses, and voice emulation to create a supportive and interactive experience.

## ✨ Features

- **Emotion Detection** – AI-powered emotion analysis from text
- **Therapeutic Responses** – Empathetic AI-driven conversation
- **Voice Emulation** – Generate responses using cloned voices
- **Speech-to-Text** – Voice input support
- **Text-to-Speech** – Audio-based AI responses
- **User Authentication** – Secure sign-up and login
- **Conversation History** – Save and retrieve past conversations
