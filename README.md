## 🎯 Features

- **Emotion Detection** - AI-powered emotion analysis from text
- **Therapeutic Responses** - Empathetic AI conversation
- **Voice Emulation** - Clone and use your voice for responses
- **Speech-to-Text** - Voice input support
- **Text-to-Speech** - Audio responses
- **User Authentication** - Secure sign up and login
- **Conversation History** - Save and retrieve chat history

## 🛠️ Tech Stack

**Backend:**
- FastAPI (Python web framework)
- PostgreSQL (Database)
- Hugging Face Transformers (AI models)
- ElevenLabs API (Voice synthesis)

**Frontend:**
- React 19
- Vite
- React Router

## ⚡ Quick Commands

### Backend
```bash
cd Backend
pip install -r requirements.txt
python main.py
```

### Frontend
```bash
cd Frontend
npm install
npm run dev
```
