# Echocare Frontend
Nathaniel Cheung and Darcy Cheung


React frontend for the Echocare therapeutic conversation application, built with Vite.

> **📖 First time setting up?** See **[GETTING_STARTED.md](../GETTING_STARTED.md)** for complete setup instructions from scratch.

## Quick Start

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Start development server:**
   ```bash
   npm run dev
   ```

3. **Open in browser:**
   - Frontend: `http://localhost:5173`
   - Make sure backend is running on `http://localhost:8000`

## Available Scripts

- `npm run dev` - Start development server
- `npm run build` - Build for production
- `npm run preview` - Preview production build
- `npm run lint` - Run ESLint

## Tech Stack

- **React 19** - UI framework
- **Vite** - Build tool and dev server
- **React Router** - Navigation
